# Artefatos do Escritório de Arquitetura (Arch360)

Espelho em arquivo dos documentos gerados pelo projeto de Onboarding no Paperclip (ARC-225). Cada arquivo corresponde à última revisão do documento no momento do commit; a fonte de verdade e o histórico de revisões continuam no Paperclip, vinculados à issue de origem indicada em cada arquivo.

- `adr/` — Architecture Decision Records (ADR-0001 a ADR-0016)
- `ar/` — Architecture References (AR-001 a AR-005, mais o AR pendente de direitos do titular)
- `governance/` — templates, registro de decisões, catálogo regulatório, processo de exceção/waiver e modelo operacional do Escritório
- `handoff/` — hand-offs da primeira onda ao comitê de arquitetura (rodadas 1 a 7)
- `plan.md` — plano original de criação do Escritório de Arquitetura (ARC-1)
