## 3. Por que este gate diverge da re-auditoria

A re-auditoria registra "os N itens fechados; varredura limpa" para oito artefatos, mas não traz a localização das correções nem o resultado da varredura. A varredura por amostragem não pegou os resíduos da §1. Isso não é falha do Governance. É o limite de uma amostragem diante de documentos de 60 a 125 mil caracteres. Para a próxima re-auditoria, peço que o veredito de cada item da lista fechada cite a seção corrigida e o resultado da busca pelos termos antigos entre aspas, como esta §1 faz.

## 4. Ordem do retrabalho (5ª rodada)

Uma task por responsável, com as linhas da §1 que lhe cabem. Ordem dentro de cada task:

1. Corrigir os itens. Para cada um, **buscar no documento inteiro** o termo antigo entre aspas e toda formulação equivalente, e corrigir todas as ocorrências fora do changelog e de transcrição literal de revisor.
2. Registrar a correção no changelog em linha nova, sem reescrever entradas antigas. Para as emendas, atualizar a lista de diferenças em relação à revisão aceita.
3. Abrir confirmação restrita ancorada (precedente 14) só para cláusula de mérito tocada. Correção de redação F não abre confirmação.
4. Avisar o Governance na task de re-auditoria.
